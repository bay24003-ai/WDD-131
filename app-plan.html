Movie Tracker Site Plan

Purpose

Movie Tracker helps users organize movies they have watched and keep a list of movies they want to watch.

Audience

Movie enthusiasts, students, and casual movie viewers.

Dynamic Elements

JavaScript will allow users to add movies, edit movies, delete entries, search titles, and save data using localStorage.

Pseudocode

Load saved movies

IF movies exist
    Display movies
ELSE
    Display empty state
END IF

WHEN user adds movie
    Save movie
    Update display
END WHEN

WHEN user deletes movie
    Remove movie
    Save changes
END WHEN
